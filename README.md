# Plataforma BI Zapata

Plataforma interna de Business Intelligence para Corporación Zapata.

## Estructura
- `frontend/` — React 19 + Vite + TypeScript
- `backend/`  — Python 3.12 + FastAPI
- `infra/`    — Terraform (infraestructura GCP)
- `pipeline/` — Ingesta de datos (Excel → BigQuery)
- `docs/`     — Documentación técnica

## Requisitos
Node.js 20+, Python 3.12+, gcloud CLI, Terraform, Docker
